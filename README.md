## Pillars Of Object Oriented Programming

### 1. [Inheritance]()

+  Inheritance is a core concept of Object-Oriented Programming (OOP) that allows one class to acquire the properties and behaviors of another. It promotes code reuse and polymorphism.

+ Types of Inheritance :
+ 1. Multilevel
+ 2. Single Level
+ 3. Hierarchical
+ 4. Hybrid
 
### 2. [Encapsulation and Polymorphism]()
+ Polymorphism is a core OOP concept that means "many forms." It allows objects to behave differently based on their class types, even when sharing the same interface or method name.
+ Types of Polymorphism
 1.Method overloading
 2.Method overriding

+ Encapsulation is one of the four fundamental OOP principles. It refers to the practice of wrapping data (variables) and code acting on the data (methods) together as a single unit and restricting direct access to some components.

### 3. [Abstraction]
+ Abstraction means hiding the internal implementation and showing only the essential features of an object. It helps you focus on what an object does, not how it does it.
